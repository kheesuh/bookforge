# 교정교열 규정 (정본)

본문 문장·표기의 정본. 적용 지점: ① 집필 계약(SKILL.md P1이 이 파일을 가리킨다) ② 편집 검수(하네스 bf-copy-editor) ③ 기계 게이트 G16(렌더 전, qc_gate.py). 레이아웃·배치는 pagination.md, 디자인은 각 STYLE.md가 정본이고, 이 파일은 **글** 층만 다룬다. 조판은 텍스트 이해에서 출발한다 — 여기 규정은 "글이 조판을 망치는 경로"를 막는 최소 규칙이다.

## 1. 문장부호

- **엠대시(—) 원칙 금지.** 삽입구는 괄호·쉼표로, 범위는 물결(~)로, 화제 전환은 문장을 끊어 쓴다. 남은 엠대시는 장당 3개까지 WARN, 4개부터 G16 FAIL. 엠대시 연쇄는 기계 생성 문체의 대표 지문이라 상업 원고에서 신뢰를 깎는다.
- 말줄임표는 …(U+2026) 1개. 마침표 3개(...) 금지.
- 인용은 큰따옴표 " ", 재인용·의미 강조는 작은따옴표 ' '. 병렬 나열은 가운뎃점(·).
- 물음표·느낌표 뒤 이중 부호(?!, !!) 금지.

## 2. 영문 표기

- **한글 문장 속 단독 영문 용어는 첫 글자를 대문자로 쓴다.** "commit 이력" → "Commit 이력", "branch 전략" → "Branch 전략". 소문자 영단어가 한글 사이에 끼면 문장이 흘러내려 용어로 읽히지 않는다.
- 예외 우선순위: ① 고유명사는 공식 표기(GitHub, macOS, npm, iPhone) ② 명령어·코드 식별자·파일명은 코드체(`git commit`, `package.json`)로 원형 유지 ③ 영어 문장 통째 인용은 영어 문법대로.
- 첫 등장 시 한글(English) 병기 후 이후 한 표기로 통일: "저장소(Repository)" → 이후 "저장소" 또는 "Repository" 하나만.
- 대소문자 혼재 금지: 같은 용어를 REST/rest/Rest로 섞지 않는다.

## 3. 숫자·단위

- 아라비아 숫자 + 천 단위 쉼표(12,500). 단위 기호는 붙인다(3GB, 15%, 42km). 우리말 단위 명사는 띄운다(3만 건, 두 가지).
- 범위는 물결(3~5회). 수치는 출처 확인분만 쓴다(G10 — 브리프·본문에 근거 없는 수치는 날조 판정).

## 4. 퀴즈·보기 문법

- **보기·선택지·단계 나열을 한 문단에 이어 쓰지 않는다.** 마크다운은 단일 줄바꿈을 공백으로 접으므로 인라인 나열(①②③이 한 문단)은 조판에서 한 덩어리가 된다 — 한 문단 원문자 3개 이상은 G16 FAIL.
- 규정 문법:

```
### 확인 문제
1. 질문 문장을 여기에 쓴다?
   - ① 보기 하나
   - ② 보기 둘
   - ③ 보기 셋

::: tip 정답과 해설
정답 ②. 해설 문장.
:::
```

- 문제는 번호 리스트, 보기는 그 아래 들여쓴 리스트(항목당 원문자 1개), 정답·해설은 콜아웃으로 분리한다.

## 5. 한국어 교열 체크리스트 (편집 검수용)

- **번역투**: "~에 대해/대한" 남발, "~을 통해", "~의 경우", "~적(的)" 연쇄, "~에 있어서" → 우리말 어순으로 고친다.
- **피동**: 이중피동("보여지다", "쓰여지다") 금지. 행위 주체가 있으면 능동으로.
- **AI 문체 지문**: "~라고 할 수 있다"·"~하는 것이 중요하다"의 반복 헤징, 문단마다 "또한/그리고/하지만"으로 시작, 모든 문단이 같은 길이·같은 리듬, "정리하면/요약하자면" 남발, 볼드 남발. 발견 시 문장을 다시 세운다 — 헤징을 지우는 게 아니라 단정할 근거가 있는지부터 본다.
- **호응**: 주어-서술어, 조사(은/는·이/가·을/를) 호응. 한 문장이 60자를 넘으면 분할을 검토한다.
- **띄어쓰기 고빈도**: "할 수 있다"(띄움), "그중"(붙임), "~뿐만 아니라"(뿐 붙임), 보조용언은 원칙 띄움.
- **어휘 통일**: 같은 개념 한 표기(첫 등장 기준). 외래어는 국립국어원 표기 우선, 업계 관용이 압도적이면 관용 따르되 전권 통일.

## 6. 표·강조의 텍스트 전제 (조판 연동)

- 표 컬럼 폭은 컨버터가 내용 길이에 비례해 자동 분배한다 — 셀에 문장을 넣으면 표가 아니라 리스트·본문이 맞는지 먼저 판단한다.
- 강조는 콜아웃(계선 박스)·볼드·인용 중 내용 성격에 맞는 하나로. 좌측 세로바 박스는 전 스타일에서 폐지됐다(디자인 정본: 각 STYLE.md).
